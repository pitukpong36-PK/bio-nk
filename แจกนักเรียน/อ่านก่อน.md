# ไฟล์สำหรับแจกนักเรียน

**ลิงก์เว็บ:** https://pitukpong36-pk.github.io/bio-nk/

- `qr-ชีววิทยา.png` — สำหรับใส่สไลด์ / พิมพ์ติดหน้าห้อง
- `qr-ชีววิทยา.svg` — สำหรับขยายใหญ่ (ป้ายไวนิล/โปสเตอร์) ไม่แตก

QR ใช้ระดับกันความผิดพลาดสูงสุด (H) — ต่อให้มีรอยเปื้อนหรือพิมพ์ไม่คมก็ยังสแกนติด

## แนะนำให้นักเรียนติดตั้งเป็นแอป

**Android (Chrome):** เปิดเว็บ → เมนู ⋮ → "ติดตั้งแอป" / "เพิ่มไปยังหน้าจอหลัก"
**iPhone (Safari):** เปิดเว็บ → ปุ่มแชร์ ⬆️ → "เพิ่มไปยังหน้าจอโฮม"

ติดตั้งแล้วเปิดได้เหมือนแอป และ**ใช้ได้แม้ไม่มีเน็ต** (บทที่เคยเปิดแล้วจะอ่านได้ตลอด)

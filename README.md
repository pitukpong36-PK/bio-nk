# ศูนย์การเรียนรู้ชีววิทยา ม.ปลาย — ครูนันธิดา คำแดง

## เปิดใช้งาน

**ดับเบิลคลิก `index.html`** ได้เลย ใช้งานได้ครบทุกอย่างแบบออฟไลน์ ไม่ต้องรันเซิร์ฟเวอร์
(ฟอนต์เก็บไว้ในเครื่องแล้ว ไม่ต้องต่อเน็ต)

⚠️ ต้องเก็บโฟลเดอร์ `css/ js/ data/ fonts/` ไว้ข้าง ๆ `index.html` เสมอ
ถ้าจะส่งให้คนอื่น ให้บีบอัดทั้งโฟลเดอร์ (zip) ไม่ใช่ส่ง `index.html` ไฟล์เดียว

## โครงสร้างไฟล์

```
index.html          หน้าเว็บ (โครง + เนื้อหาหน้าแรก/สื่อ/ใบความรู้)
css/main.css        สไตล์ทั้งหมด
css/fonts.css       ประกาศฟอนต์ (ชี้ไปที่ fonts/)
fonts/*.woff2       ฟอนต์ Prompt + Sarabun เก็บในเครื่อง
js/app.js           โค้ดทั้งหมดของเว็บ

data/meta.js        ★ สร้างอัตโนมัติ — หัวบท 29 บท + จำนวนโจทย์
data/search.js      ★ สร้างอัตโนมัติ — ดัชนีค้นหา
data/quiz.js        ★ สร้างอัตโนมัติ — คลังโจทย์ 544 ข้อ
data/vol1..6.js     ✏️ เนื้อหาบทเรียน แยกตามเล่ม  ← แก้ที่นี่

_build/build.py     สคริปต์สร้างไฟล์ ★ จากเนื้อหาใน vol*.js
_build/split.py     สคริปต์แยกไฟล์เดียวเป็นหลายไฟล์ (ใช้ครั้งเดียวตอนแปลง)
_archive/           เวอร์ชันเก่าและไฟล์สำรอง
```

## ✏️ วิธีแก้เนื้อหาบทเรียน

1. เปิด `data/vol<เล่ม>.js` — เช่น บทที่ 15 อยู่เล่ม 4 → `data/vol4.js`
2. แก้ HTML ในบทที่ต้องการ (อยู่ระหว่างเครื่องหมาย backtick `` ` ``)
3. **ถ้าแก้โจทย์หรือหัวข้อ `<h3>` ต้องรันคำสั่งนี้ทุกครั้ง:**
   ```bash
   cd "~/Desktop/05_NK Web site project/NK Website"
   python3 _build/build.py
   ```
   ไม่รัน = แบบทดสอบกับช่องค้นหาจะยังเป็นข้อมูลเก่า

> **ห้ามแก้** `data/meta.js`, `data/search.js`, `data/quiz.js` ด้วยมือ
> ทั้งสามไฟล์ถูกเขียนทับทุกครั้งที่รัน `build.py`
> **แหล่งความจริงมีที่เดียวคือ `data/vol*.js`**

### ข้อควรระวังเวลาเพิ่มโจทย์
รหัสโจทย์คือ `<บท>#<ลำดับ>` เช่น `b1c1#0`
- เพิ่มโจทย์ **ต่อท้ายบท** = ปลอดภัย
- **แทรกกลางบท** = ประวัติการทบทวนของข้อที่อยู่หลังจุดแทรกจะเลื่อนไปผูกกับข้ออื่น

## โครงสร้างโจทย์ (ให้ build.py อ่านเจอ)

```html
<div class="problem-topic-header">📑 หมวด A — ...</div>
<div class="problem-card">
  <h4>โจทย์ที่ 1 — ...</h4>
  <div class="problem-statement"><strong>โจทย์:</strong> ...</div>
  <details class="solution-details"><summary>เปิด/ปิด วิธีทำ</summary>
    <div class="solution-content"><strong>วิธีคิด:</strong><br>...</div>
  </details>
</div>
```
ครบ 4 ส่วนนี้ระบบจะดึงเข้าคลังโจทย์ให้เอง

## สิ่งที่ยังไม่ได้ทำ (เฟส 1)

- ยังไม่ขึ้นเว็บจริง — ยังไม่มี git / GitHub Pages
- ยังไม่มี PWA (`sw.js`, `manifest.webmanifest`) ติดตั้งเป็นแอปไม่ได้
- ยังไม่มีระบบสมาชิก — ความก้าวหน้าเก็บในเบราว์เซอร์เครื่องเดียว
  (ส่งออก CSV / สำรอง JSON ได้ที่หน้า "ความก้าวหน้า")
